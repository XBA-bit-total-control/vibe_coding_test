# Список задач

Веб-приложение для ведения личного списка задач. После регистрации можно создавать задачи с описанием, менять названия и 
статусы, отмечать задачи выполненными и удалять их. Список сохраняется в PostgreSQL. Доступны фильтр по статусу и сортировка по дате добавления.

Проект использует Django, Django REST Framework, Uvicorn и PostgreSQL. OpenAI Codex использовался для разработки интерфейса, 
настройки Docker и проверки приложения.

Временное развертывание доступно по адресу: https://todo-web-site.duckdns.org/

## Запуск через Docker Compose:

Понадобятся Git, запущенный Docker и Docker Compose.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/XBA-bit-total-control/vibe_coding_test.git vibe_coding_test
cd vibe_coding_test
```

### 2. При необходимости создать `.env`

Для локального запуска этот шаг можно пропустить. Чтобы переопределить настройки, скопируйте шаблон .env-example и заполните нужные поля в редакторе.

```bash
cp .env-example .env
```

| Переменная      | Значение по умолчанию                    |
|-----------------|------------------------------------------|
| `SECRET_KEY`    | `django-insecure-todo-local-development` |
| `DB_PASSWORD`   | `todo-local-password`                    |
| `DB_NAME`       | `todo`                                   |
| `DB_USER`       | `todo`                                   |
| `ALLOWED_HOSTS` | `127.0.0.1,localhost`                    |
| `WEB_PORT`      | `8000`                                   |

Compose задаёт `DEBUG=False`, `DB_ENGINE=django.db.backends.postgresql`, `DB_HOST=db` и `DB_PORT=5432` внутри контейнера. 
Для публичного развертывания задайте собственные `SECRET_KEY` и `DB_PASSWORD`.

### 3. Собрать и запустить контейнеры

```bash
docker compose up --build -d
```

Статика собирается при сборке образа. Compose ждёт готовности PostgreSQL Alpine, после чего Django применяет миграции и запускается через Uvicorn. 
Откройте [127.0.0.1:8000](http://127.0.0.1:8000/) и зарегистрируйтесь. Если порт занят, укажите `WEB_PORT=8001` в `.env` и откройте
[127.0.0.1:8001](http://127.0.0.1:8001/).

Регистрация не требует подтверждения чего-либо. Она предназначена только затем, чтобы сохранять за конкретным пользователем его задачи. 

Чтобы посмотреть журналы приложения, выполните `docker compose logs -f web`.

### Для остановки приложения и удаления контейнеров:

```bash
docker compose down
```

Задачи и учетные записи остаются в локальном томе Docker `postgres_data` после остановки и удаления контейнеров. 
Команда `docker compose down -v` удаляет том вместе с данными.
